## 模块概述

- 页面路径：`/ctrl/agent/skills`（侧边栏「技能库」）
- 核心功能：技能列表 + 搜索 + 手动创建 + 编辑 + 删除 + ZIP 下载 + 公开/私密切换 + 文件夹批量上传 + 共享技能只读查看
- 数据来源：后端 API `/web/config/skills`（RESTful CRUD + `/upload` 批量导入）
- 页面元素（真实 DOM 探查）：
  - 标题「技能管理」、副标题「管理 AI Agent 可用的全局技能模板」
  - 顶部按钮：`上传技能`、`新建技能`
  - 搜索框：`input[placeholder*='搜索技能']`
  - 分组：`私有技能`（计数）、`他人共享技能`（计数）
  - 私有技能卡片：`下载` / `编辑` / `删除` 按钮 + `公开` 开关
  - 共享技能卡片：`下载` / `查看` 按钮 + `只读` 标记
  - 创建弹窗（`dialog` 元素）：标题「新建技能」，字段 `技能名称`（placeholder `my-skill`）/ `描述`（`可选，简要描述技能用途`）/ `内容`（`输入 Markdown 内容...`），按钮 `取消` / `保存`
  - 编辑弹窗：标题「编辑技能」，`技能名称` 输入框 `disabled`，描述/内容可编辑
  - 删除确认：`alertdialog`「确认删除」，正文「此操作不可逆。确定要删除技能 "X" 吗？」，按钮 `取消` / `确认`
  - 上传弹窗：标题「上传技能」，文案「点击选择包含技能的文件夹」「每个子目录将被识别为一个 skill，目录内需包含 SKILL.md」，`input[type=file]`，按钮 `取消` / `开始上传`（未选文件时禁用）
  - 校验提示：sonner toast（`[data-sonner-toast]` / `[role=status]`）
    - 空名称 → `名称不能为空`
    - 名称填、内容空 → `内容不能为空`
    - 创建成功 → `技能已创建`
    - 公开切换 → `设为公开` / `设为私有`

## 后端约束（源码：src/services/skill-fs.ts `assertValidSkillName`）

- 名称必须非空（trim 后）
- 名称不能为 `.` / `..`
- 名称不能包含 `/` 或 `\`（路径分隔符）
- 同名内部技能重复创建 → 409 CONFLICT
