## 第 2 条 `test_workflow_has_create_button`

**用例说明**：智能体编排页面有新建工作流按钮

**评审问题**：
- [ ] 断言不够充分：只检查了按钮是否存在（`count() > 0`），未检查按钮是否**可见**（`is_visible()`）和是否**可点击**（`is_enabled()`）
- [ ] 文案耦合：通过按钮文字 `"新建工作流"` 定位，如果产品改了文案就会误报失败

**建议修改**：
```python
def has_create_button(self) -> bool:
    btn = self.page.get_by_role("button", name="新建工作流")
    return btn.count() > 0 and btn.first.is_visible() and btn.first.is_enabled()
```

**评审结论**：用例存在，需增强断言

## 侧边栏模块整体覆盖缺口

**模块定位**：test_sidebar.py 验证侧边栏作为**导航入口的可用性**，不重复各页面的深度功能测试。

**校验维度**：
1. **导航可达性**：点击每个菜单项 → URL 正确 → 页面加载成功 → 无 JS 报错
2. **侧边栏结构完整性**：菜单分组（核心/配置）存在、菜单项齐全
3. **侧边栏交互**：当前激活状态高亮

**当前覆盖（6/14）**：智能体编排、记忆、知识库、定时任务、组织、API Key

**缺失菜单项（8 个）**：

| # | 分组 | 菜单项 | 目标路由 | 备注 |
|---|------|--------|---------|------|
| 1 | 核心 | 新建智能体 | 弹窗/新页面 | 可能触发弹窗而非跳转，需确认交互形式 |
| 2 | 核心 | 智能体管理 | `/ctrl/agent/agents` | 其他文件有深度测试(test_agent.py)，此处只验导航 |
| 3 | 配置 | 模型库 | `/ctrl/agent/models` | 其他文件有深度测试(test_model_config.py) |
| 4 | 配置 | 垂直模型库 | `/ctrl/agent/vertical-models` | 其他文件有深度测试(test_vertical_models.py) |
| 5 | 配置 | 算法库 | `/ctrl/agent/algorithms` | 其他文件有深度测试(test_algorithms.py) |
| 6 | 配置 | 技能库 | `/ctrl/agent/skills` | 其他文件有深度测试(test_skills_v2.py) |
| 7 | 配置 | MCP | `/ctrl/agent/mcp` | 其他文件有深度测试(test_mcp.py) |
| 8 | 配置 | Agent Sites | `/ctrl/agent/sites` | 其他文件有深度测试(test_sites.py) |

**补充建议**：
- 每个缺失菜单项补一条 P0 导航可达性用例：点击菜单 → 验证 URL → 验证页面加载 → 验证无 console.error
- 额外补一条 P1 侧边栏结构完整性用例：断言菜单分组和菜单项数量
- "新建智能体"需先确认交互形式（弹窗 vs 跳转），再决定断言方式

**评审结论**：需补充 8 条导航用例 + 1 条结构完整性用例
