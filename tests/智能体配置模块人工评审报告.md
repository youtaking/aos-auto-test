## 全局问题

### 1. API 端点不一致
`POST /web/agents` 返回 200 但不创建 Agent，正确端点是 `POST /web/config/agents`，body 结构也不同。已在 Page Object 的 `create_agent_api` 中修正。

### 2. Agent 创建需要配套 Environment
仅创建 Agent 配置不够，还需 `POST /web/environments` 创建运行环境才能在 UI 中点击进入对话。已在 `create_agent_api` 中自动创建。

### 3. 保存后必须重启
配置 modal 保存后弹出"配置已保存，需要重启智能体实例才能生效"对话框，必须点击"重启"按钮修改才会生效。所有保存操作均已添加重启步骤。

### 4. 配置按钮作用域
每个 Agent 卡片有独立的配置按钮，需先定位到目标 Agent 的父容器 `div.agent-sidebar-agent`，再在其中点击 `button[title="智能体配置"]`，否则会点错 Agent。
