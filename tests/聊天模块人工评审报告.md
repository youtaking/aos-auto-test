## 全局问题：被测系统 `/web/organizations` 接口控制台报错

**发现方式**：在 conftest.py 中新增全局 `_page_error_monitor` fixture（监听 console.error / API 4xx/5xx / pageerror）后，所有用例均检测到以下错误：

```
[request] GET /web/organizations TypeError: Failed to fetch
Failed to load org context: ApiError: 网络异常，请检查连接
```

**分析**：
- 接口本身正常返回 200，数据正确
- 报错原因是前端 `OrgContext` 组件在 SPA 路由切换时存在**竞态问题**：某个请求在 auth token 未就绪时发出，短暂失败后被 catch 并重试成功
- 前端用 `console.error` 记录了已处理的瞬态错误，应降级为 `console.warn`

**结论**：不算功能 bug，属于前端代码质量问题

**建议**：
1. 通知前端开发：将 `OrgContext` 中已处理的重试错误从 `console.error` 降级为 `console.warn`
2. 测试框架：在全局错误监听中加白名单过滤此类已知瞬态错误，避免掩盖真正的 bug
